# Ale Canteiro Digital – ebook shop site

Static site for ALE CANTEIRO DIGITAL LTD (England & Wales, company no. 16767917). Plain HTML/CSS.

- `index.html` library, how it works, FAQ
- `terms.html`, `privacy.html`, `refunds.html`, `contact.html`
- `covers/` SVG covers

Each `Buy now` button (`data-book`) links to a Stripe Payment Link. Deploy with GitHub Pages (main branch, root).
